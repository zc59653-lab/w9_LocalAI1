提示詞逐一列出並說明功能（中文）

下面將系統提示詞中的 10 點約束，逐一用繁體中文列出並說明其在生成教材時的功能與作用：

  1. 原文： Be a single file with all content inline (no external CSS/JS/image URLs).

    功能說明： 確保生成的 HTML 教材僅為一個 .html 檔案，所有樣式、行為與圖片皆透過內聯方式寫在檔案內部，使用者無需下載額外資源，離線即可完整閱讀與使用。

  2. 原文：> Embed all icons and illustrations as SVG directly in the HTML.

    功能說明： 所有圖示、流程圖與裝飾圖均以 SVG 碼直接寫在 HTML 中，避免依賴外部圖片連線，防止圖片載入失敗或被網路過濾，同時減少對 CDN 的依賴。

  3. 原文： Not reference any external image CDN or URLs.

    功能說明： 明確禁止在 HTML 中出現任何外部圖片網址（如 Imgur、GitHub raw CDN 等），這是為了保證教材的離線特性，使用者儲存檔案後無需網路即可瀏覽。

  4. 原文： Feature top-of-page tabs that switch content sections.

    功能說明： 在頁面頂部放置標籤導航列，使用者可直接點選「安裝 Ollama」、「驗證運行」、「模型下載」等章節，跳轉對應內容，提升教材的可讀性與瀏覽效率，減少手動滾動尋找的時間。

  5. 原文： Include a specific tag: "不得引用外部圖片 URL" somewhere in the content or metadata.

    功能說明： 作為一個強制審核關鍵字，確認生成的 HTML 內容是否真的遵守「不得引用外部圖片 URL」的規定，同時提醒閱讀者與開發者注意這項限制。

  6. 原文： Model usage: First model Llama 3.2, second model Mistral.

    功能說明： 明確教材將針對這兩個特定模型編寫步驟與範例。讀者可以依照說明先下載 Llama 3.2 作為入門模型，再嘗試 Mistral 作為第二模型進行對比，確保教學路徑明確、模型選擇有據。

  7. 原文： Include hardware requirements, step-by-step commands, verification commands, and FAQ.

    功能說明： 確保教材完整涵蓋電腦硬體最低需求（如 RAM、儲存空間、GPU 設定），提供每一步的具體指令（如 ollama pull、docker run），說明如何驗證服務是否正常運行，以及收錄常見問題與解決方案，幫助新手避開常見坑。

  8. 原文： Add interactive elements: code copy buttons, tab switching via JavaScript.

    功能說明： 在程式碼區塊底部加入「一鍵複製」按鈕，讓使用者能直接複製指令；透過 JavaScript 實現標籤頁的平滑切換與狀態管理，提升教材的實用性與現代網頁體驗。

  9. 原文： Contain a footer crediting the student: 國立清華大學數理教育研究所 陳冠宇研究生.

    功能說明： 在頁尾註明教材的作者與歸屬，建立學術來源與責任歸屬，同時也是此 HTML 檔案出處的身份認證，符合教育資源的規範與歸屬性。

  10. 原文： The tutorial must be suitable for complete beginners, with clear instructions and troubleshooting.

    功能說明： 確保教材的敘述語言簡單易懂，步驟標註清楚，並釀排常見錯誤與解決方案，讓完全沒有 AI 或 伺服器 經驗的新手也能跟隨完成從安裝到跑通的全過程。

提示詞設計要點表格

次序 設計要點 核心目的
1 單一自包含 HTML 檔 讓教材成為一個獨立的 .html 檔案，使用者僅下載一次即可離線永久使用，無需額外安裝或網路連線。
2 SVG 圖片內嵌（無外部圖片 URL） 確保教材在離線環境下圖示與流程圖能正常顯示，避免因為圖片連線失敗而導致教材閲讀中斷。
3 繁体中文語言環境 照顧台灣、香港與馬來西亞等地區使用者的語言習慣，讀者無需翻譯即可理解每一步驟與說明。
4 頁首標籤分頁導航 使用者可直接點選章節標籤切換內容，提升瀏覽效率，減少手動滾動尋找資訊的時間成本。
5 明確模型組合（Llama 3.2 + Mistral） 先以輕量的 Llama 3.2 作為入門範例，再以 Mistral 作為第二模型進行對比，引導讀者依硬體能力自選模型。
6 硬體需求、指令與 FAQ 說明最低 RAM、建議儲存空間、Docker 等需求；提供具體的 ollama 與 docker 指令；收錄常見連線失敗、模型慢等問題的解決方案。
7 互動元件（一鍵複製、JavaScript 標籤切換） 使用者可直接複製程式碼區塊的指令；透過點選標籤即時切換章節，提高教材的實用性與現代網頁體驗。
8 頁尾作者認證 註明「國立清華大學數理教育研究所 陳冠宇研究生」，建立教材出處、學術誠信與責任歸屬。
9 適合完全新手 語言簡單、步驟細緻、輔以故障排除說明，讓零經驗使用者也能跟隨完成整個架設流程。
10 不得引用外部圖片 URL 強制約束，確保生成的 HTML 檔案絕對離線可用，避免因外部連線失敗或內容被封鎖而導致教材效果大幅降低。
